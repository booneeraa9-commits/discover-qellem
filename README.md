# Discover Qellem

Discover Qellem is a bilingual digital archive and public-information platform
for Qellem Wallaggaa.

## Languages

- Afaan Oromoo is the mandatory and authoritative content language.
- Reviewed English translations are published separately.

## Approved architecture

- Next.js and TypeScript public frontend
- Django and Wagtail editorial backend
- PostgreSQL database
- Docker Compose development and deployment
- Caddy HTTPS reverse proxy
- AletCloud production VPS

## Current phase

Phase 3: development foundation.

## Important repository rule

Private source documents, credentials, contributor information, unapproved
photographs, and production secrets must never be committed to this repository.
