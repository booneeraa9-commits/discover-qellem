# Sponsors and collaborators

This app stores approved public recognition data only. Sponsor contracts, payment values, private contacts, and unrelated personal data do not belong in these records.

A sponsor or collaborator is eligible for later public output only when `partner_is_approved_for_public_display()` returns true. A selected logo or portrait must also have a complete, approved `MediaRights` record. English recognition text may remain pending, but required Afaan Oromoo public text cannot be omitted from an approved record.
